# Online Shop

An online shopping platform built using **HTML**, **CSS**, and **JavaScript**. This project allows users to browse products, view product details, add items to their cart, and manage orders through a dashboard. It also features a responsive design that adapts to various screen sizes.

## Features

- **Homepage**: Displays a list of products fetched from a mock API.
- **Product Details**: Users can click on a product to see more details.
- **Search Functionality**: Filter products by title using the search bar.
- **Pagination**: Navigate through product pages using "Next" and "Previous" buttons.
- **Cart**: A simple shopping cart system to track added products.
- **Dashboard**: View and manage orders. Users can cancel orders directly from the dashboard.

## Technologies Used

- **HTML**: Structure of the website.
- **CSS**: Styling with custom styles and Tailwind CSS for responsiveness.
- **JavaScript**: For dynamic content, API requests, search, pagination, and order management features.

## Features of the Dashboard

- **View Orders**: After checkout, users can view their order details, including product names, quantities, and prices.
- **Cancel Orders**: Users have the ability to cancel their orders from the dashboard. 

## Setup

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/OnlineShop.git
    ```
2. Open the project folder in your code editor (e.g., Visual Studio Code).
3. Launch the project by opening the `index.html` file in a browser.

## Files and Directories

- `index.html`: The homepage with product listings and navigation.
- `shop.html`: The shop page where products are displayed.
- `cart.html`: The shopping cart page.
- `dashboard.html`: The dashboard page where users can view and cancel orders.
- `css/`: Contains the custom styles for the website.
- `js/`: JavaScript files for handling interactions like search, pagination, and API requests.
- `modules/`: Reusable modules for authentication and order management.

## Usage

1. Visit the **homepage** to view a list of products.
2. Use the **search bar** to filter products by title.
3. Navigate between product pages using the "Prev" and "Next" buttons.
4. Click on a product to view its detailed page.
5. Add products to your **cart** and proceed to checkout.
6. Visit the **dashboard** to view your orders and manage them by canceling if needed.
